# AgroMaster

Учебный прототип для ведения реестра сельскохозяйственных полей и журнала работ. В приложении есть резервное копирование в JSON и встроенные проверки. Все исходные записи демонстрационные.

[Открыть AgroMaster](https://loilset00.github.io/agromaster/)

Для запуска на компьютере откройте `index.html` в браузере. Изменения сохраняются в хранилище браузера. Для воспроизводимых проверок можно добавить к адресу `?demo=1`.

В истории Git тег `v1.0.0` отмечает версию, в которой принималась нулевая площадь, а `v1.0.1` — версию после исправления. Изменение сделано в ветке `fix/positive-area`.
